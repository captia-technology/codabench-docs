# Referencia

**Objetivo:** resolver un síntoma concreto cuando algo no responde como se esperaba, y saber en qué fuente se apoya cada afirmación de esta guía.

Esta sección no forma parte del montaje. Se consulta desde cualquier punto del recorrido, cuando la competición no se comporta como debería o cuando hace falta contrastar lo que dice la guía con la documentación oficial de Codabench.

- [**Troubleshooting**](./troubleshooting.md) — tabla de síntoma y causa probable: leaderboard vacío, submission que no termina, una Task que no aparece al configurar la fase o un participante que no puede enviar nada.
- [**Fuentes y documentación oficial**](./fuentes.md) — los enlaces de los que sale esta guía, incluido el método alternativo del bundle YAML que aquí no se cubre.

Si el síntoma no está en la tabla, el primer sitio donde mirar son los logs `stdout`/`stderr` de la propia submission, que Codabench deja disponibles para cada una.
