# Tasks

**Objetivo:** combinar los recursos ya subidos en una Task, la unidad reutilizable que después se asigna a una o varias Phases.

Ir a **Resources → Tasks**.

## Crear la Task

1. Click **Create Task**.
2. Rellenar **nombre** y **descripción** de la task (qué debe predecir/resolver el participante).
3. Seleccionar de los recursos ya subidos en [el paso anterior](./datasets-programs.md):
   - Input data
   - Reference data
   - Ingestion program (opcional)
   - Scoring program (obligatorio)

Codabench permite tener varias Tasks por competición y asignar más de una Task a la misma Phase — útil si la competición tiene varias subtareas evaluadas por separado.

**Siguiente paso:** [Fases y evaluación](../evaluacion/index.md) — las etapas temporales que usan esta Task y las tablas donde se publican sus resultados.
